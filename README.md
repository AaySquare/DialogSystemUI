A dialogue system project which allows one to simulate dialogue between 2 or more speakers. The speaker's dialogue is played with a typewriter effect and each dialogue can have a special keyword which is highlighted with a different color, and if you hover over it, a popup widget will show explaining what the keyword means. 

The dialogue system is fully customizable via editor itself so it is very designer friendly.
